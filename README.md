# Y-Mad (Young For Madagascar Development)

Plateforme web complète pour l'association Y-Mad.

## 🚀 Technologies

- **Frontend**: Next.js 14, TypeScript, TailwindCSS
- **Backend**: NestJS, PostgreSQL, TypeORM
- **Auth**: JWT, Bcrypt
- **Paiements**: MVola, Orange Money, Airtel Money

## 📋 Fonctionnalités

- ✅ Authentification (7 rôles)
- ✅ Gestion des membres avec QR code
- ✅ Module emploi (offres + candidatures)
- ✅ Gestion d'événements
- ✅ Dons Mobile Money
- ✅ Blog bilingue (FR/MG)
- ✅ Dashboard admin complet
- ✅ Rapports PDF
